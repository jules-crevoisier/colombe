# Raccourcis clavier

Colombe reprend les raccourcis clavier de Gmail : de quoi naviguer et agir sans quitter le
clavier. Un point d'interrogation (`?`) les affiche à tout moment depuis l'application.

::: tip
Les raccourcis sont ignorés pendant que vous tapez dans un champ (objet, corps du message,
recherche…) : pas de risque d'archiver un message par erreur en écrivant son contenu.
:::

## Partout

| Touche | Action |
|---|---|
| `c` | Nouveau message |
| `/` | Rechercher |
| `?` | Afficher les raccourcis |
| `Ctrl + Entrée` | Envoyer le message en cours de rédaction |

## Dans la liste des messages

| Touche | Action |
|---|---|
| `j` / `k` | Message suivant / précédent |
| `Entrée` | Ouvrir le message |
| `x` | Sélectionner |
| `s` | Étoile |
| `e` | Archiver |
| `#` | Supprimer |

## Dans un message ouvert

| Touche | Action |
|---|---|
| `r` | Répondre |
| `a` | Répondre à tous |
| `f` | Transférer |
| `e` | Archiver |
| `#` | Supprimer |
| `u` | Retour à la liste |
