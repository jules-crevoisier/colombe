# Premiers pas

Colombe est la messagerie web de votre établissement : elle affiche le courrier qui vit
sur le serveur de votre établissement, dans un navigateur, sans rien installer. Cette page
explique comment se connecter, ce que vous voyez à l'écran, et comment lire ou écrire un
message en deux minutes.

## Se connecter

1. Ouvrez l'adresse de Colombe donnée par votre établissement.
2. Saisissez votre adresse e-mail (ou seulement votre identifiant, si votre établissement
   l'autorise) et votre mot de passe habituel — celui de votre messagerie, pas un mot de
   passe propre à Colombe.
3. Si la double authentification est activée sur votre compte, un second écran demande un
   code à 6 chiffres depuis votre application d'authentification.

::: tip Mot de passe oublié ?
Colombe ne gère pas les mots de passe. Un lien « Mot de passe oublié ? » sur la page de
connexion, quand votre établissement l'a configuré, vous renvoie vers son propre outil.
:::

## Se connecter avec le compte de l'établissement

Si votre établissement l'a activé, un bouton unique sur la page de connexion vous
identifie avec votre compte habituel (le même que pour l'ENT ou les autres services de
l'établissement) : plus de mot de passe à saisir dans Colombe. Après avoir choisi votre
compte chez votre établissement, vous revenez automatiquement sur votre boîte de
réception.

Si Colombe propose aussi la connexion par mot de passe, elle reste accessible sous le
bouton, derrière un lien « Se connecter avec un mot de passe » — utile par exemple pour un
compte qui n'existe pas dans l'annuaire de l'établissement.

Ce que ça change au quotidien :

- **La double authentification de Colombe**, si vous l'avez activée dans vos paramètres,
  continue de s'appliquer en plus — un second facteur propre à Colombe, indépendant de
  votre compte d'établissement.
- **Créer ou modifier un transfert ou une redirection** vous redemande de vous identifier
  auprès de votre établissement (au lieu d'un mot de passe Colombe) : une fenêtre de 5
  minutes s'ouvre après ce retour pour confirmer votre modification.
- **Se déconnecter** de Colombe peut aussi vous déconnecter de votre compte
  d'établissement, selon la configuration choisie par votre établissement.
- Un lien **« Retour à l'ENT »**, s'il est configuré, ramène vers le portail de votre
  établissement depuis la page de connexion.

## L'écran principal

Une fois connecté, trois zones :

- **À gauche (ou en haut sur mobile) : les dossiers.** Boîte de réception, Envoyés,
  Brouillons, Corbeille, Spam, Archives, et les dossiers que vous avez créés. Un chiffre
  indique les messages non lus.
- **Au centre : la liste des messages** du dossier ouvert, avec expéditeur, objet, un
  court aperçu et la date.
- **À droite (à partir de 1024 px de large) : le message lu**, dans un volet séparé qui
  reste à côté de la liste — pratique pour enchaîner la lecture. En dessous de cette
  largeur, ouvrir un message occupe tout l'écran ; un bouton retour ramène à la liste.

## Lire un message en 30 secondes

Cliquez sur un message dans la liste pour l'ouvrir. Il est marqué lu automatiquement
(immédiatement, ou après un court délai réglable dans **Paramètres → Général**). Les
images distantes (logos, photos hébergées ailleurs) sont bloquées par défaut : un bandeau
propose de les afficher pour ce message si vous faites confiance à l'expéditeur. Voir
[Lire, écrire, répondre](/guide/messages) pour le détail.

## Écrire un message en 1 minute

Le bouton **Nouveau message** (ou le raccourci clavier `c`) ouvre une fenêtre de
rédaction : destinataire (avec autocomplétion depuis vos contacts), objet, corps du
message avec mise en forme si vous le souhaitez, pièces jointes par glisser-déposer.
L'envoi part après un court délai annulable (réglable dans **Paramètres → Général**), et
un brouillon est conservé automatiquement pendant que vous rédigez.

## Langue de l'interface

Colombe est disponible en **français** et en **anglais** (*English*). Par défaut, il suit
la langue de votre navigateur ; si celle-ci n'est ni le français ni l'anglais, il prend la
langue choisie par votre établissement.

- **Sur la page de connexion**, le sélecteur **FR | EN** en haut change la langue tout
  de suite ; ce choix est retenu par ce navigateur.
- **Une fois connecté**, choisissez **Paramètres → Général → Langue / Language** :
  *Automatique (langue du navigateur)*, *Français* ou *English*. Le changement
  s'applique immédiatement, sans recharger la page, et suit votre compte sur tous vos
  appareils.

La langue choisie s'applique aussi aux messages d'erreur, aux dates, aux tailles de
fichiers, à la citation insérée quand vous répondez (« Le …, … a écrit : » / « On …, …
wrote: ») et à l'alerte envoyée par Colombe quand un transfert est modifié sur votre
compte. Les dossiers spéciaux changent de nom à l'affichage (Boîte de réception → Inbox,
Envoyés → Sent…) ; leur nom sur le serveur de messagerie ne change pas, vos autres
logiciels ne voient aucune différence.

## Sur mobile

L'interface s'adapte à partir de 320 px de large : une colonne à la fois (dossiers, puis
liste, puis message), boutons assez grands pour le doigt, et aucun geste de pincement
nécessaire pour lire le texte. Les mêmes fonctions sont disponibles ; seule la disposition
change.
