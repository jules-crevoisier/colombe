# Signaler une vulnérabilité

Merci de **ne pas** ouvrir de ticket public pour une faille de sécurité.

Utilisez le signalement privé de GitHub : onglet **Security → Report a vulnerability** du
dépôt. Indiquez la version concernée (`GET /api/health`), les étapes pour reproduire et
l'impact estimé. Vous recevrez un accusé de réception sous 72 heures ouvrées.

Versions maintenues : la dernière version publiée. Les correctifs de sécurité font
l'objet d'une version dédiée, annoncée dans `CHANGELOG.md`.

Modèle de sécurité et recommandations d'exploitation :
[docs/admin/securite.md](docs/admin/securite.md).
